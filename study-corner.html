Coding

Coding is the creative process of giving instructions to a computer.
It helps me turn ideas into useful projects and solve problems in an imaginative way.

Learn more about coding Jump to how I study it

Why I like it

  • I can build useful things from simple ideas.
  • There is always something new to learn.
  • Solving bugs feels like solving a puzzle.

How I study it

  1. I learn one concept from a lesson or tutorial.
  2. I practise it by writing a small example.
  3. I review my work and fix any errors.

Words to know

Algorithm
A clear set of steps used to solve a problem.
Bug
An error in a program that makes it behave unexpectedly.
